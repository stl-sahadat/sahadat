## Features & Architecture

1. **Floating Glass Header:**
   - Smooth backdrop blur navigation with active scrollspy links.
   - Clean URL history routing without hash fragments.
   - Sequential navigation layout matching page scroll: About Me -> Projects -> Showcase -> Experience -> Skills -> Contact.

2. **Hero Section with Signature Visuals:**
   - Transparent high-resolution cutout portrait of **Md Sahadat Hossain**.
   - 360-degree rotating ambient blur blobs behind the profile image.
   - Dual split-text typography: `AI Agent Architect & Prompt Engineer`.
   - Rotated quick-download Resume pill button and vertical social bar (LinkedIn, GitHub, WhatsApp, Direct Mail).

3. **About Me:**
   - Authentic architectural narrative from primary GitHub repository (`stl-sahadat/my-portfolio`).
   - 3 Core Targets: 10x Execution Velocity, 70% Cost Compression, Zero-Hallucination Resilience.

4. **Featured Projects Carousel:**
   - Built on `Swiper.js` with auto-play, grab cursor, and touch-swipe capabilities.
   - 8 authentic production applications including **Morning Mug Coffee House** (Live GitHub Pages Demo), **Cloud Expense Tracker Suite** (Google Cloud Run), **Autonomous AI Web Builder**, **Enterprise RAG Knowledge Engine**, **Neural Pulse Ops Telemetry**, **Talent Intelligence Resume AI**, **Crypto Quant High-Frequency Terminal**, and **CrewAI Workflow Automation Swarm**.

5. **Visual Showcase / Gallery:**
   - Interactive visual cards displaying System Architecture Topologies, Realtime Latency Telemetry, and RAG Knowledge retrieval.
   - Built-in interactive lightbox modal with zoom preview and escape-to-close.

6. **Work Experience & Education Tabs:**
   - Central timeline line (`.work__line`) with tab switching between Career Experience and Academic Education.
   - 4 authentic engineering milestones: Lead Automation & Systems Architect, Full-Stack Systems Engineer, Product & Web Architect, Cloud Solutions Consultant.

7. **Technical Skills & Battle-Tested Tech Tools:**
   - Positioned at the bottom directly before Contact for cohesive layout hierarchy.
   - Interactive 3-card skill accordion (Autonomous AI, Spatial Web, Backend/Cloud).
   - Dual-row infinite rotating marquee with 44 tech badges (Python, FastAPI, Docker, Cloud Run, CrewAI, LangChain, Claude, GPT-4o, etc.).

8. **1-Click Clipboard Email Copy:**
   - Direct copy to clipboard with instant checkmark feedback.
   - Direct WhatsApp, LinkedIn, GitHub, and mailto action links.

9. **Live CMS & Admin Console:**
   - Anti-brute-force rate limiting gate.
   - Full live data management and real visitor analytics tracking.
